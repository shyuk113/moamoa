# KOCCA 공모전·지원사업 연동

## 데이터와 표시

- 공식 데이터: [한국콘텐츠진흥원 지원사업공고](https://www.data.go.kr/data/15134251/openapi.do), [KOCCA 명세](https://www.kocca.kr/kocca/subPage.do?menuNo=204796&gubun=tab01).
- 요청 주소는 `https://kocca.kr/api/pims/List.do`이며 KOCCA가 발급한 `serviceKey`를 사용한다. 공공데이터포털의 다른 서비스 키와 혼동하지 않는다.
- 자유공모·지정공모·모집공고를 `공모전·지원사업` 분야로 제공한다. 모두 일반 개인 대상 공모전이라는 의미가 아니며, 상세에 원본 분류와 원본 링크를 표시한다.
- `startDt`/`endDt`는 접수 기간이다. 행사 운영 기간과 혼동하지 않으며 캘린더도 접수 기간을 저장한다. API는 날짜만 제공하므로 정확한 마감 시각은 원본에서 확인해야 한다.
- API에 구조화된 지역·대상·제출 방법이 없으므로 지역을 서울/전국으로 추측하지 않는다. 지역과 자격 확인 안내를 표시하며 본문과 원본을 제공한다.
- 본문은 텍스트로 정리하고 화면에서도 HTML로 실행하지 않는다. 사진은 API에 없는 항목으로 임의 수집하지 않는다.

## 키와 실행

인증키 파일은 저장소 밖에 두며 한 줄 원문 또는 `KOCCA_API_KEY=...` 형식을 사용한다.

```powershell
.\scripts\start-local.ps1 -ApiKeyFile '서울시 키 파일 경로' -KoccaApiKeyFile 'KOCCA 키 파일 경로' -SyncOnStart
```

IDE/배포 환경에서는 `KOCCA_API_KEY` 환경변수에 원문 키를 설정한다. 시작 스크립트는 percent-encoded 키도 해제하여 읽는다. `KOCCA_ENABLED=false`로 중지할 수 있고 키가 없으면 자동 비활성화된다. API 키·요청 URL·응답 본문은 오류 로그에 기록하지 않는다.

## 수집과 갱신

- 한 페이지 최대 100건. 실제 `INFO.listCount`는 현재 페이지의 건수이므로 전체 건수로 해석하지 않는다. 100건 미만 또는 `INFO-200`까지 다음 페이지를 요청한다.
- 기본 진행 공고와 `cate=4` 종료 공고를 조회한다. 종료 공고는 신규 저장하지 않지만 기존 공고의 내용을 갱신하고 `source_closed=true`로 표시한다. 날짜를 조작하지 않고 목록·추천·알림에서 제외하며 즐겨찾기와 상세는 보존한다.
- `intcNoSeq`는 식별키로 사용하지 않는다. 공식 원본 링크의 `intcNo`를 `(KOCCA, sourceId)` 고유키로 사용하며 URL 호스트와 경로를 검증한다.
- 정상 행만 매핑하고 날짜/식별자 오류는 집계한다. 인증 실패·스키마 불일치·반복 페이지·상한 초과 시 결과 전체를 반환하지 않아 부분 수집을 저장하지 않는다. 다른 소스 수집은 기존 실패 격리 정책으로 계속한다.
- `KOCCA_MAX_PAGES`는 진행/종료 각각 최대 페이지 수(기본 200)다. 숫자 상한은 기관의 이용 한도와 별개이며, 공식 공개 안내에는 일일 호출 한도가 명시되어 있지 않아 실제 계정 정책을 우선한다.
- 기존 스케줄(06시/18시), 관심분야 알림과 즐겨찾기를 공통 사용한다. 소스 간 자동 중복 병합은 아직 하지 않는다.

## 검증

- 2026-09-22 실제 인증: HTTP 200, `INFO-000`. 진행 공고 5건 및 다음 페이지/종료 분류 응답을 확인했다.
- 자동 검증: 원본 ID, URL/날짜 검증, 텍스트 변환, 페이지 처리와 종료 갱신, 오류 시 키 비노출, 비활성화, 검색·상세·즐겨찾기·마감 알림 연결.
- 최종 전체 테스트 41개 통과(실패·오류·건너뛰기 0), 실행 JAR 빌드 성공.
- 실제 초기 수집: 2,124건 조회, 신규 5건, 종료 공고 등 2,118건 신규 저장 제외, 유효하지 않은 행 1건 제외. 재수집: 신규 0건, 갱신 5건으로 중복 없음.
- 현재 노출 중인 KOCCA 5건과 서울 140건의 정규화 제목 및 기간 겹침 비교에서 일치 0건. 이는 현재 표본의 정확 매칭 결과이며 과거 데이터나 유사 제목까지 중복이 없다는 보장은 아니다.
- 브라우저에서 공모전·지원사업 목록 5건, 한국어/영어 상세의 접수 기간·원본 링크·추천 지역 표시를 확인했다. 실제 키가 변경 파일에 포함되지 않음을 확인했다.

출처 표시는 공공누리 제1유형에 따라 한국콘텐츠진흥원을 포함한다.
