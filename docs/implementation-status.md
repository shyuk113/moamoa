# 구현 및 검증 기록

기준 계획: noble-questing-balloon.md, 2026-09-14.

## 사용자와 확정한 변경

- 서울시 전시·미술 / 박람회 / 지역·계절 축제를 추가한다.
- 서울시 API는 실제 인증키로 검증했다: HTTP 200, INFO-000, 당시 전체 19,532건.
- KOCCA 키 승인은 대기 중이므로 실연동과 소스 간 중복률 비교는 승인 이후로 보류한다.
- 서울시 행사 종료일과 공모전 접수 마감일을 구분한다.

## 구현

- [x] Java 21, Spring Boot, PostgreSQL, Flyway, QueryDSL.
- [x] 행사·회원·관심분야·즐겨찾기·알림 테이블 및 검색 인덱스.
- [x] 서울시 페이지 단위 조회, 대상 분야 분류, 종료 데이터 제외, 원본 분류 보존.
- [x] 원본 페이지 주소 기반 멱등 업서트, 소스별 실패 격리/3회 경고.
- [x] 검색/기간 겹침/지역/무료/참여 방식 필터, 상세와 D-day.
- [x] JWT HttpOnly 쿠키, CSRF, 회원가입/로그인, 실패 5회 15분 잠금(DB 저장 및 계정 행 잠금).
- [x] 해시된 재설정 토큰, 만료/재사용 방지, 변경 전 JWT 무효화.
- [x] 즐겨찾기 멱등 등록/해제 및 목록 상태 배치 조회.
- [x] 관심분야/알림 빈도 화면, 신규·종료 임박·주간 메일.
- [x] PostgreSQL Testcontainers 기반 통합 테스트.

## 검증 결과 (2026-09-15)

- 자동 테스트 28개 통과: 실패 0, 오류 0, 건너뛰기 0.
- 실제 서울시 초기 수집: 19,532건 조회, 신규 159건 저장.
- 반복 수집: 신규 0건, 갱신 159건, 유효하지 않은 데이터 11건. 반복 실행에서 중복 추가가 없음을 확인했다.
- 브라우저에서 로그인, 즐겨찾기 등록/해제, 관심분야·주간 알림 설정 저장을 확인했다.
- 데스크톱 홈과 390px 모바일 설정 화면을 확인했다. 재설정 메일은 로컬 Mailpit에서 수신했다.
- 인증된 정적 파일 요청이 CSRF 쿠키를 지우던 문제를 수정하고 실제 쿠키/HTML 토큰 흐름의 회귀 테스트를 추가했다.

## 외부 의존 및 한계

- KOCCA 실제 클라이언트/매퍼와 API 양쪽의 중복률·호출 한도 확인은 승인 이후.
- 프로젝트 식별자는 moamoa이며 실행 스크립트는 현재 프로젝트 경로와 VERSION을 기준으로 동작한다.
- 공개 저장소 `https://github.com/shyuk113/moamoa`를 생성했다. 구현은 PR로 제출하며 KOCCA 승인 후 연동을 후속 진행한다.
- 서울시 원본 주소가 없는 행사의 ID는 복합 필드 기반이다. 해당 필드 변경 시 완벽한 중복 판정은 불가능하다.
- 기본 검색은 content/count 2회, 로그인 시 즐겨찾기 상태 조회 1회가 추가된다. 페이지 크기에 따른 N+1은 없다.
- 비밀번호 재설정은 발송 속도 제한(계정별 1분)을 적용한다. IP별 rate limiter는 기존 계획대로 후속 과제다.
